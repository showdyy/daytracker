# Трекер дня

Приложение-трекер для телефона: еда с автоподсчётом калорий и БЖУ, тренировки, вода, сон, вес, настроение,
рутина (утро / день / вечер) и дела. Работает без сервера и без интернета — все данные хранятся только на устройстве.

Открой страницу на телефоне и добавь её на главный экран («Поделиться» → «На экран Домой» в Safari или
«Установить приложение» в Chrome).
